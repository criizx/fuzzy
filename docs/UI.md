# Интерфейс лаборатории

Пересобран после обратной связи 8 ноября 2026.

## Направление

Настольный инструмент для численных экспериментов. Нейтральный интерфейс, системная типографика, один акцент для действий. Никаких рекламных заголовков, декоративных карточек и отдельных блоков KPI. Ориентир — плотность рабочих интерфейсов и инспекторов свойств; принципы Linear использованы для иерархии и единых компонентов, без копирования маркетинговой страницы.

## Разбор предыдущей версии

| Приоритет | Проблема | Изменение |
|---|---|---|
| Major, Nielsen 8 | Большой декоративный заголовок отодвигал исследование | Компактная строка названия |
| Major, Nielsen 7 | Длинная панель с настройками и кнопкой ниже экрана | Инспектор справа; диапазоны и случайность раскрываются отдельно |
| Major, Nielsen 8 | Карточки, подписи и статистика конкурировали с графиками | Единая рабочая область и небольшая строка состояния |
| Major, Nielsen 6 | Два уменьшенных графика было трудно исследовать | Переключаемые вкладки на всю рабочую ширину |
| Minor | Цветная редакционная стилистика не соответствовала задаче | Нейтральные поверхности, системный шрифт, синий акцент |
| Major, mobile | До графиков нужно было пролистать все параметры | На мобильном инспектор свёрнут при открытии |

## Структура

Шапка с двумя разделами. Под ней одна рабочая область: графики и результаты слева, инспектор справа. Вкладки «α-срезы» и «Плоскость границ» сохраняют выбор при пересчёте. Под графиком таблица кластеров, ниже раскрываемые исходные величины. Арифметика использует тот же каркас. Подробная модель доступна в справке.

Все функции расчётной библиотеки и маршруты сохранены. Вкладки поддерживают Tab, стрелки и Home/End. На мобильном инспектор раскрывается через summary. Графики имеют имена и численные альтернативы. Светлая и тёмная темы используют единые переменные theme.css.

Применены локальные навыки redesign, apply-aesthetic и ux-writing; выполнен разбор по design-review и проверка доступности по a11y-audit. Отчёты измерений находятся в docs/qa. Оценка эстетики остаётся субъективной; прохождение автоматических проверок не означает одобрение дизайна пользователем.

Эвристический taste_audit отмечает небольшой контраст размера заголовка и текста. Это осознанное решение для рабочего инструмента: крупный display-заголовок был удалён по обратной связи пользователя. Все измеренные проверки контраста текста и интерактивных состояний проходят в обеих темах.
