# Проверки после разделения ответственности

Дата: 8 ноября 2026.

## Go

Проверки текущего рефакторинга:

```sh
go test ./...
go test -race ./...
go vet ./...
```

Добавлены проверки аналитических вероятностных характеристик, полной вероятностной массы, различия плотности и функции принадлежности, воспроизводимости seed, независимости снимков, кеширования и инвалидирования результатов. Сохранены проверки отказа журнала и повторной попытки. Архитектурный тест контролирует плоские пакеты `internal`/`cmd` и разрешённые направления импортов.

## Браузер

`scripts/regression-ui.cjs` самостоятельно собирает и запускает приложение на свободном локальном порту с временными данными. Проверены оба порядка задержанных запросов, общая очередь htmx, неактуальные поля облаков, сетевые ошибки, повтор ошибки, восстановление и тайм-аут. Сценарий обновлён под явные кнопки расчёта.

`scripts/check-ui.cjs` запускается против отдельного тестового сервера; адрес задаётся через `LAB_URL` (по умолчанию localhost:8080). Этот сценарий изменяет набор **на указанном сервере**, поэтому нельзя направлять его на рабочую пользовательскую сессию. Проверены α, поля алгоритмов, генерация 120 величин, сохранение темы, все четыре операции, валидация σ и обе страницы на ширинах 320, 390, 768, 1024 и 1440 px. Ошибки JavaScript и горизонтальное переполнение страницы не обнаружены.

Для сценариев требуется Playwright. `PLAYWRIGHT_MODULE` задаёт путь к установленному модулю, `CHROME_CHANNEL` — канал браузера (по умолчанию chrome; можно указать chromium), `PLAYWRIGHT_BROWSERS_PATH` — каталог браузеров Playwright. Это необязательные инструменты QA, не зависимости приложения.

## Новые материалы

Файлы с префиксом `refactor-` относятся к новой архитектуре и интерфейсу:

- `refactor-browser-results.json`: ошибки страницы и переполнение.
- `refactor-clustering-desktop.png`, `refactor-clustering-dark.png`, `refactor-clustering-mobile.png`.
- `refactor-arithmetic-desktop.png`, `refactor-arithmetic-mobile.png`.
- `refactor-clustering.html`, `refactor-arithmetic.html`: статические HTML-снимки.

Результаты Go-проверок представлены в выводе команд, а не в старом `ui-gates.txt`.

## Исторические материалы и ограничения

Снимки без префикса `refactor-`, `browser-results.json` и `ui-gates.txt` сохранены от предыдущего интерфейса. Их результаты контраста и эвристических дизайн-проверок **не переносятся** на новую версию. Новый полный аудит WCAG, проверка экранным диктором и измерение контраста всех состояний не выполнялись. Браузерные проверки и адаптивность не заменяют такой аудит.
