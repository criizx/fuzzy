# Проверки готовой лабораторной

Дата: 8 ноября 2026.

## Go

- `go test ./...`: все пакеты проходят.
- `go test -race ./...`: все пакеты проходят, гонки не обнаружены.
- `go vet ./...`: замечаний нет.
- `go build ./cmd/app`: приложение собирается с встроенными ресурсами.
- Дополнительный тест сравнивает численную площадь логнормальной нечёткой модели с независимым аналитическим интегралом и проверяет сходимость при увеличении сетки.

## Интерфейс

`browser-results.json` содержит результат Playwright-проверки текущего приложения в Chrome. Сценарий: `scripts/check-ui.cjs`; требуется запущенный localhost:8080 и пакет playwright (для QA, не для работы приложения).

Проверены синхронизация числового α и ползунка, обновление htmx, переключение полей алгоритмов, генерация 120 величин, сохранение выбранной темы, сложение/вычитание/умножение/деление, отклонение σ=0 формой и сервером. Ошибок JavaScript нет.

Обе страницы проверены на ширинах 320, 390, 768, 1024 и 1440 px. Горизонтального переполнения страницы нет; большие таблицы имеют свой контейнер прокрутки. Графики имеют текстовые имена, таблицы данных и подписи. Скриншоты просмотрены визуально, подписи мобильных графиков увеличены. В новой версии инспектор на мобильном свёрнут, графики переключаются вкладками. Проверены стрелки на вкладках и сохранение выбранного графика после htmx-пересчёта.

`ui-gates.txt`: запуск проверок локального навыка design-code на сохранённых HTML-снимках приложения. measure_render проверяет контраст текста; verify_states проверяет светлую и тёмную темы, default/hover/focus интерактивных элементов; taste_audit выполняет эвристическую проверку композиции. Это не полный аудит WCAG и не проверка каждого состояния экранным диктором.

Статические проверки: lint_hardcodes — без ошибок в новых шаблонах и стилях компонентов; validate_theme_refs — все CSS-переменные определены; check_no_emoji — без ошибок.

Общий `accuracy_report.mjs` навыка также запускался. Его проверки собственных демонстрационных страниц не прошли браузерную часть, поскольку Playwright не установлен рядом с самим навыком. Этот отчёт не является аудитом данного проекта. Для проекта браузерные проверки выполнены отдельно через доступный bundled Playwright; их фактический результат сохранён в ui-gates.txt. Утверждение о полном прохождении всего набора проверок навыка не делается.
