Как выполняются операции

Арифметика выполняется над α-срезами. Результат может иметь другую форму, чем исходные величины.

Pos: возможность A ≥ B. Nec: необходимость A ≥ B.

Справка: модель и точность

Логнормальная плотность нормирована по максимуму: g(x) = exp(−(ln x − μ + σ²)² / (2σ²)), x > 0. Для конечного носителя используем μ̃(x) = max(0, (g(x) − ε)/(1 − ε)), ε = 10⁻⁴.

α-срез: [exp(μ − σ² − σ√(−2 ln β)), exp(μ − σ² + σ√(−2 ln β))], β = ε + (1 − ε)α. При α = 1 остаётся мода exp(μ − σ²).

Арифметика и интегральные характеристики используют 200 шагов по α. ε задаёт уровень относительной плотности, а не вероятность хвоста. Сумма и разность обычно не являются логнормальными величинами.
