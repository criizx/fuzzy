# Исправления после независимого ревью

Проверены пять найденных ошибок:

1. Обновления графиков, генерация и сохранение/загрузка используют одну последовательную очередь htmx. Задержанный ответ не заменяет новый набор; операции изменения данных не отменяются последующим запросом просмотра.
2. Неактуальные поля groups/noise выключаются вместе со скрытием и не участвуют в проверке формы. Сервер требует их только в режиме clouds.
3. Обрыв соединения, HTTP-ошибка и тайм-аут явно сообщаются пользователю. Предыдущий результат помечается как не обновлённый; aria-busy сбрасывается, повторные ошибки не дублируются.
4. Генерация и загрузка меняют набор только после успешной записи журнала. Форма генерации обновляется вместе с набором; дедупликация отмечает только удачные записи. Закрытый журнал воспроизводит ошибку записи, восстановление проверяется повтором операции.
5. Необходимость A≥B вычисляется через дополнение строгого обратного отношения B>A. Для совпадающих чётких величин необходимость равна 1; для непрерывных функций сохраняется вычисление супремума.

## Повторение проверок

```sh
go test -race ./...
go vet ./...
```

Дополнительная необязательная зависимость для браузерных проверок — Playwright и Chrome. Установленный пакет можно указать переменной PLAYWRIGHT_MODULE.

```sh
node scripts/regression-ui.cjs
```

Сценарий самостоятельно собирает приложение, запускает его на свободном локальном порту с временным каталогом данных и завершает после проверки. Пользовательский localhost:8080 и его набор не меняются. Проверяются оба порядка задержанных запросов, наследование очереди сохранением/загрузкой, переключение режима, сетевые ошибки, восстановление и тайм-аут. Материалы исходного design QA в этой папке относятся к внешнему виду; эти исправления меняют поведение, сохраняя композицию интерфейса.
