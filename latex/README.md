# Отчёт по практической работе

Авторы: Сетраков Фёдор, Коваленко Денис. Группа М8О-410Б-23.

Сборка: `make` через Tectonic (`brew install tectonic`) либо `make xelatex` через XeLaTeX (два прохода для содержания). В Overleaf загрузите весь архив, выберите компилятор XeLaTeX и основной файл report.tex. При отсутствии Microsoft-шрифтов используются FreeSerif, FreeSans и FreeMono.

В архиве-образце преподаватель не указан, поэтому его имя в новый титульный лист не добавлено. Оформление и группа взяты из образца; содержание адаптировано под текущую логнормальную реализацию.

Изображения images/*.jpg — новые снимки запущенного приложения от 15.11.2026, коммит b3dbee8. Старые изображения из примера не использовались. В разделе демонстрации приведены наблюдавшиеся результаты; дополнительные исследования явно обозначены как план.

Готовый PDF: `report.pdf`. Служебные файлы сборки и ZIP-копия исключены из Git.
