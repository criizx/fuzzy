# Lognormal Lab

Вычислительная лаборатория для исследования логнормальных нечётких величин: генерация наборов, α-срезы, кластеризация и арифметика. Go, HTML, SVG и htmx; без внешних Go-зависимостей и сборки frontend.

## Запуск

Требуется Go 1.24.7 или новее. Из корня проекта:

```sh
go run ./cmd
```

Откройте http://localhost:8080. Другой адрес и каталог данных:

```sh
go run ./cmd -addr localhost:8081 -data ./data
```

## Сценарий эксперимента

1. Задать диапазоны μ и σ, seed, режим генерации и количество 100–300.
2. Нажать **«Создать и посмотреть набор»**. Предварительный просмотр не запускает кластеризацию: отдельно показаны исходная плотность и функция принадлежности первых трёх величин. В таблице доступны все объекты и их вероятностные характеристики.
3. Выбрать α, PAM с числом кластеров либо иерархический метод со средней связью и порогом. Нажать **«Запустить кластеризацию»**.
4. Изучить интервалы, плоскость границ, размеры групп и медоиды. Изменение параметров применяется по кнопке; переключение вида графика не запускает расчёт.
5. На странице **«Операции»** задать два операнда, выбрать действие и нажать **«Рассчитать»**.

Текущий набор общий для всех вкладок. Приложение предназначено для локальной работы, без пользователей и базы данных. Seed воспроизводит набор при одинаковых настройках генерации. Для CSV без метаданных seed неизвестен — приложение не подставляет вымышленное значение.

## Архитектура

Все Go-пакеты, кроме точки входа, находятся в `internal`. Подпакетов внутри предметных пакетов нет.

```text
cmd/                    конфигурация, создание зависимостей, HTTP-сервер
internal/
    distribution/       логнормальная плотность, CDF, мода, медиана, E[X], Var[X]
    fuzzy/              нечёткая модель, интервалы, α-срезы, операции, метрики
    clustering/         PAM и average-linkage над матрицами расстояний
    generator/          воспроизводимые наборы и облака параметров
    experiment/         сценарии, состояние набора, результаты и ограниченный кеш
    storage/            проверка и сохранение CSV
    logger/             журнал JSON Lines
    web/                HTTP, HTML-модели, геометрия графиков, встроенные ресурсы
```

`distribution` не зависит от нечёткой логики. `fuzzy` использует вероятностную модель, но не знает о HTTP, CSV или журнале. `experiment.Service` координирует генерацию, хранение, вычисления и запись журнала через интерфейс `Journal`. `web` только разбирает запросы и готовит представление. `cmd` собирает зависимости. `templates` и `static` — каталоги ресурсов, не Go-пакеты. GoDoc написан на английском.

Сервис защищает состояние mutex-ом, возвращает независимые снимки и сохраняет только последний результат каждого вида расчёта. Повтор одинаковой кластеризации текущего набора не пересчитывает матрицу и не дублирует журнал. Генерация и загрузка инвалидируют результат. Ошибка журнала не заменяет текущий набор и не помечает неудачный расчёт как успешно записанный.

Старый равномерный тип оставлен **только в `_test.go`** как аналитический эталон для регрессий общего нечёткого ядра. В рабочей программе используется логнормальная модель.

## Математическая модель

`ln X ~ N(μ, σ²)`, `σ > 0`. Параметры μ и σ относятся к **ln X**, а не к X.

```text
f(x) = exp(-(ln x - μ)²/(2σ²)) / (x σ sqrt(2π)), x > 0
mode = exp(μ - σ²)
median = exp(μ)
E[X] = exp(μ + σ²/2)
Var[X] = (exp(σ²)-1) exp(2μ+σ²)
```

Вероятностная плотность может превышать единицу. Она не используется напрямую как функция принадлежности. Принято отдельное модельное решение:

```text
g(x) = f(x)/f(mode) = exp(-(ln x - μ + σ²)²/(2σ²))
μ̃(x) = max(0, (g(x)-ε)/(1-ε)), ε = 10⁻⁴
β = ε + (1-ε)α
Aα = [exp(μ-σ²-σ sqrt(-2 ln β)), exp(μ-σ²+σ sqrt(-2 ln β))]
```

При α=0 берётся замыкание рабочего носителя, при α=1 — мода. ε задаёт уровень относительной плотности, **не вероятность хвоста**. `Density` и `CDF` описывают исходное неусечённое распределение; `Membership` и `AlphaCut` — компактную нечёткую модель. График плотности показывает конечное рабочее окно, но сам вероятностный носитель остаётся бесконечным.

Арифметика выполняется по принципу обобщения через 200 шагов по α. Результат хранится как `fuzzy.Cuts` и не обязан быть логнормальным. Это не свёртка вероятностей независимых случайных величин. Возможностные среднее и дисперсия в разделе операций отличаются от E[X] и Var[X] в таблице исходных данных.

Для устойчивости нечёткого ядра логарифмы границ рабочего носителя ограничены диапазоном [−160,160]; конструктор также отклоняет слишком малое σ. Численные интегралы и нелинейные результаты зависят от разрешения α-сетки.

Формула распределения: [NIST](https://itl.nist.gov/div898/handbook/eda/section3/eda3669.htm). Нормирование и отсечение — явные допущения этой реализации. Подробности — в `docs/REPORT.md`.

## CSV и журнал

Сохранение: `<data>/<имя>.csv`. Загрузка: `<data>/input/<имя>.csv`. Каталог `data` задаётся флагом `-data`.

```csv
kind,mu,sigma
lognormal,0,0.3
lognormal,0.7,0.4
```

Загрузчик принимает от 1 до 300 величин. Формат хранит исходные параметры без округления, но не seed и не результаты нечёткой арифметики. Старый формат `kind,a,b` не поддерживается: он описывает другую модель.

`<data>/log.json` содержит JSON Lines: генерацию с настройками и seed, загрузку и сохранение, параметры кластеризации, размеры групп, операции и ошибки. Для логнормальных операндов записываются μ, σ и ε.


```sh

```

Для браузерных проверок нужны Playwright и Chrome. Путь к установленному Playwright можно задать через `PLAYWRIGHT_MODULE`. Для обычного запуска приложения они не нужны. Материалы проверок и ограничения старых снимков описаны в `docs/qa/README.md`.
