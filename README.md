# Lognormal Lab

Лабораторная работа: нечёткие величины на основе логнормального распределения.
Реализация на Go с локальным веб-интерфейсом на HTML, CSS, SVG и htmx.

## Запуск

Нужен Go 1.24.7 или новее. Внешних Go-зависимостей нет.

```sh
git clone https://github.com/criizx/kubrik.git
cd kubrik
go run ./cmd/app
```

Откройте http://localhost:8080. Остановить сервер: Ctrl+C.

Другой адрес и каталог данных:

```sh
go run ./cmd/app -addr localhost:8081 -data ./data
```

```sh
go test ./...
go vet ./...
```

## Что умеет программа

- Генерация 100–300 логнормальных нечётких величин: случайные параметры либо облака с шумом.
- Кластеризация PAM с заданным k и иерархическая кластеризация со средней связью и порогом.
- Изменение α с пересчётом разбиения; графики интервалов, плоскости границ и таблицы данных.
- Сложение, вычитание, умножение, деление и сравнение двух величин.
- Центр тяжести, возможностные среднее и дисперсия; библиотека расстояний и ранжирования.
- Сохранение и загрузка CSV, журнал JSON Lines, светлая и тёмная темы, адаптивная вёрстка.

## Математическая модель

На фотографии варианта задана **плотность вероятности**, а не готовая функция принадлежности:

`f(x) = exp(-(ln(x)-μ)²/(2σ²)) / (x σ sqrt(2π))`, `x > 0`, `σ > 0`.

Здесь μ и σ — среднее и стандартное отклонение **ln X**, а не X.
Плотность может превышать 1. Поэтому её нельзя напрямую использовать как нормированную функцию принадлежности. Выбран следующий способ перехода:

1. Мода `m = exp(μ-σ²)`.
2. Нормированная плотность `g(x) = f(x)/f(m) = exp(-(ln(x)-μ+σ²)²/(2σ²))`.
3. Конечная нечёткая модель `μ̃(x) = max(0, (g(x)-ε)/(1-ε))`, `ε = 10⁻⁴`.
4. Для уровня α вводим `β = ε+(1-ε)α`. Тогда срез:
   `[exp(μ-σ²-σ sqrt(-2 ln β)), exp(μ-σ²+σ sqrt(-2 ln β))]`.

Это **явное приближение** нормированной плотности, выбранное для конечных интервалов, арифметики и визуализации. ε — уровень относительной плотности, а не вероятность отброшенного хвоста. При α=0 берётся замыкание рабочего носителя, при α=1 — мода. Исходные плотность и CDF доступны отдельно, без отсечения.

Формула исходного распределения сверена с [NIST](https://itl.nist.gov/div898/handbook/eda/section3/eda3669.htm). Нормирование и отсечение — принятые в этой реализации модельные решения, а не дополнительные условия на фотографии.

## Файлы и журнал

Сохранение: `data/<имя>.csv`. Загрузка: `data/input/<имя>.csv`.
Для примера введите `example.csv` и нажмите «Загрузить».

```csv
kind,mu,sigma
lognormal,0,0.3
lognormal,0.7,0.4
```

Загрузчик принимает до 300 величин. CSV исходного проекта `kind,a,b` нужно преобразовать: это другая модель и другие параметры. Сохраняются исходные логнормальные величины; результаты арифметики представлены универсальными α-срезами и в этот CSV не экспортируются.

`data/log.json` содержит по одной JSON-записи на действие: время, генерацию и её параметры, кластеризацию и размеры групп, операции и носители результатов. Для логнормальных операндов отдельно записываются μ, σ и ε.

## Библиотечное использование

```go
a, err := number.NewLogNormal(0, 0.3)
if err != nil { panic(err) }
b, _ := number.NewLogNormal(0.7, 0.4)
sum, err := ops.Add(a, b, core.Config{AlphaLevels: 400})
if err != nil { panic(err) }
cut, ok := sum.AlphaCut(0.5)
```

Импорты: `fuzzylab/fuzzy/number`, `fuzzylab/fuzzy/ops`, `fuzzylab/fuzzy/core`.

## Структура

- `fuzzy/core`: интерфейс Number, интервальная арифметика, настройки и ошибки.
- `fuzzy/number`: LogNormal, универсальные Cuts, контуры графиков. Uniform оставлен для совместимости и тестов общего ядра; интерфейс приложения работает с LogNormal.
- `fuzzy/ops`, `compare`, `metrics`, `set`: арифметика, сравнение, характеристики, метрики, коллекции.
- `gen`, `cluster`: генерация и алгоритмы кластеризации.
- `storage`, `logger`: CSV и журнал.
- `web`, `cmd/app`: HTTP-приложение и встроенные ресурсы.
- `docs/REPORT.md`: теория, реализация и руководство для лабораторной.
- `docs/qa`: скриншоты и результаты проверок интерфейса.

## Ограничения

По умолчанию используется 200 шагов по α: нелинейные результаты и интегралы приближённые. Увеличение `AlphaLevels` позволяет проверить сходимость. Исходные α-срезы LogNormal вычисляются аналитически. Сумма и разность обычно не принадлежат исходному семейству.

Арифметика нечёткая, по принципу обобщения: она не вычисляет распределение суммы независимых случайных величин. Повторное использование одной величины не учитывает зависимость операндов; например, A−A имеет ненулевую ширину.

Для устойчивости машинных вычислений границы логарифмов рабочего носителя должны лежать в [−160,160]; конструктор отклоняет выход за диапазон и слишком малое σ. Деление запрещено, если носитель делителя содержит 0; у допустимых исходных LogNormal нижняя граница строго положительная.

Приложение предназначено для локальной работы: один общий набор для всех вкладок, без базы данных и пользовательских сессий. Сервер по умолчанию доступен только на localhost.
